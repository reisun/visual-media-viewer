# Visual Media Viewer v0.6.0

## 更新内容

- タイトルバーの右クリックメニューに「Windowsとの連携」を追加。ファイルの関連付け候補への登録と、エクスプローラーのサムネイル対応を個別に設定できます。
- 任意の連携部品はユーザーごとの固定場所へ配置し、ポータブル版のフォルダーを移動しても登録先が壊れない構成にしました。
- JPEG・PNGなどのサムネイルはWindows標準処理で直接生成し、画像・動画の読み取りと解析も効率化しました。
- エクスプローラー経由でサムネイルが生成されない原因となり得るCOMスレッド宣言の不整合を修正。Windows実機で動作確認済みです。
- アプリアイコンを刷新し、タスクバーにアイコンが正しく表示されない問題を修正。Windows実機で動作確認済みです。
- 正式ZIPは本体・必要なDLL・ライセンスのみを同梱。検証スクリプト・診断ツール・プレビュー・バックアップは含みません。

## 更新時の注意

ZIPをすべて展開して `VisualMediaViewer.exe` を起動してください。
Windows連携を有効にしている場合は、**Windowsとの連携...** から登録済み部品を更新してください。
固定済みタスクバーのアイコンが古い場合は、固定を解除して新しい実行ファイルを再固定してください。

本体は引き続きポータブル版です。Windows連携は任意・ユーザー単位の登録で、既定のアプリはWindowsの設定画面から選択します。アプリが既定設定を強制的に書き換えることはありません。
